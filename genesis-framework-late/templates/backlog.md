# Backlog

*Worked example: [`genesis/backlog.md`](../../genesis/backlog.md), this repository's own backlog.*

*The one list where open points live until they are resolved. Save it as `genesis/backlog.md`.
A capture stays as written, the record of its moment; every open line in it is carried here.
An agent adds items when it closes its session. An item is struck as resolved only on the
author's ruling.*

| item | source | who acts | destination | status |
| :--- | :--- | :--- | :--- | :--- |
| <the open point, in one line> | <the capture or file it came from> | author, agent, or both | <where it lands: a chapter, a file, a release> | open |

**Status:** *open*; *in progress*; *resolved, <date>*, with the ruling or the commit that settled
it. Resolved items move to the end of the table, so the open ones stay on top.

---

## Why it is kept this way

| part | why |
| :--- | :--- |
| one list, outside the captures | a capture is dated and rarely reopened; an open point left in it fades with the session |
| the source | the capture keeps the full context, and the backlog points back to it |
| who acts | resolution takes both sides; each item says whose move it is |
| the destination | an item is resolved when its content lands where it belongs, beyond being answered |
| struck only on the author's ruling | the author decides what is settled |
