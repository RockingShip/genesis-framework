*A short file every agent reads on waking, beside the awakening. Where `voice.md` teaches an agent

**How to build it.** Collect the author's own statements about how they communicate, and the
moments where an agent misread a message and the author corrected it. Quote the author exactly and
leave those quotations unmarked; mark your own inferences `[READING]`. Build only from what the
author has actually said or done, then ask the author to correct the file.
