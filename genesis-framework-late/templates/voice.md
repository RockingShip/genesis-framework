# Voice: <author name or handle>

*The case study keeps its full voice document private; its opening section is public as [`case-study/VOICE-0-Reading-the-Author.md`](../../case-study/VOICE-0-Reading-the-Author.md).*

*A model of the author, for agents drafting in the author's name. Build it from the author's own
prose and from their own words when they correct a draft. Replace each `<…>` and delete these italic
notes. The examples in italics below belong to an invented author, a retired lighthouse engineer
writing a history of coastal signalling; replace every one of them with your own.*

**How to build it.** Collect specimens before descriptions: an agent imitating a description writes
pastiche, and an agent imitating a specimen writes closer. Quote the author exactly and leave those
quotations unmarked. Mark everything you infer `[READING]`, and mark every question only the author
can settle `[AUTHOR-VERIFY]`. Then ask the author to correct the file, because the next agent will
draft from it.

**How agents use it.** Read §0 on waking. Read §1 to §3 before drafting prose in the author's name.
Run §4 as a checklist before a draft reaches the author.
