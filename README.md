# genesis-framework

A working method for writing a long manuscript together with AI agents, across many sessions and many agents.

Every agent session starts fresh. The Genesis Framework gives each newcomer the same way in: an awakening file to read first, a short set of conduct rules that each carry their reason, a choice of working modes, and a capture habit so that what a session learns outlives it. The author keeps the final word. Agents act as challengers and as co-authors, and every change to the manuscript waits for mutual consensus.

## Models

The framework has been shaped with two models, and each version names the model it was configured for.

* Versions up to v8.2.3 were written with, and tuned to, Gemini 3.1 Pro.
* Versions from v9 onward are written with, and tuned to, Claude Opus 5.5.

How well a version carries over to other models is an open question, and this repository will record the evidence as it arrives.

## Versioning

Framework documents follow [Semantic Versioning](https://semver.org/): each document names its version in its title and file name. The [changelog](CHANGELOG.md) records every change to the repository.
